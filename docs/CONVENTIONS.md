# 物理與程式慣例

所有 solver（TMM、RCWA、FDTD、mode solver）**必須一致**。要改慣例，先改這份文件，再全面修改程式並重跑測試。

## 物理慣例

| 項目 | 慣例 |
|---|---|
| 時間相依 | **e^{-iωt}**，平面波 exp(i(k·r − ωt))。損耗材料 n = n' + i·k，k > 0；ε = n²，ε'' > 0 |
| 長度單位 | **μm**（波長、週期、厚度、網格都用 μm） |
| 波長／頻率 | 介面以真空波長 λ₀ [μm] 為主；內部用 k₀ = 2π/λ₀ [1/μm] |
| 座標軸 | z 為分層堆疊方向。入射介質在最上方（z 最小），光往 +z 傳播，最後一層是基板（出射介質）。週期方向為 x（1D），或 x、y（2D） |
| 入射角 | θ：波向量與 +z 的夾角（在入射介質中量）。φ：波向量在 xy 平面上的投影與 +x 的夾角。入射介質必須無損耗（n 為實數） |
| 偏振 | 入射面為 xz（φ = 0）時：TE／s = E 只有 E_y；TM／p = H 只有 H_y。1D grating 的光柵線沿 y，所以 TE = E_y 平行光柵線 |
| kz 分支 | kz = √(εk₀² − kx² − ky²)，取 Im(kz) ≥ 0（往 +z 衰減）；Im(kz) = 0 時取 Re(kz) ≥ 0 |
| 場正規化（頻域） | H̃ = i·η₀·H。在 e^{-iωt} 下 Maxwell 方程式變成 ∇×E = k₀H̃、∇×H̃ = k₀ε_r E（Rumpf 用 e^{+jωt} 與 H̃ = −jη₀H，照抄他的程式時要把 j 換成 −i） |
| 場正規化（FDTD） | 實數場，H̃ = η₀H（E 與 H̃ 同單位） |
| 振幅係數 | TMM 的 r_s、t_s 是 E_y 的比值；r_p、t_p 是 H_y 的比值 |
| 功率 | R、T 為 z 方向 Poynting flux 比值；A = 1 − R − T。無損耗結構必須滿足 R + T = 1（測試必檢） |

## 程式慣例

- 小函式、單一職責，例如 `buildConvMatrix`、`solveLayer`、`smatrixStar`。
- 函式開頭用 `arguments` block 驗證輸入。
- 批次維度：TMM 以波長為第 1 維、入射角為第 2 維。RCWA 的矩陣運算佔第 1、2 維，批次放在第 3 維之後，方便 `pagemtimes`／`pagefun` 與 `gpuArray`。
- 材料以 `n` 矩陣傳入 solver（大小 1×M 或 Nλ×M），材料模組（`src/common`）負責從表格或模型算出 `n`。
- 不在 solver 內 `disp` 或印大量輸出，只回傳結構體；印出交給呼叫端。
- 每個 solver 模組都要在 `tests/` 有對應的驗證測試，並寫明容忍誤差。
- 跑程式前先執行 `setupPaths`（測試會自動執行）。

## 必備驗證案例

1. 均勻薄膜：TMM 結果等於解析 Fresnel／Airy 公式。
2. 均勻薄膜：RCWA 結果等於 TMM。
3. 無損耗結構：R + T = 1。
4. RCWA 收斂：諧波數 N 增加時結果單調收斂。
5. 週期結構：RCWA 與 FDTD（週期邊界）結果吻合（Phase 4）。
